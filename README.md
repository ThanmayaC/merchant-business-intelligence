# Merchant Business Intelligence

AI-powered full-stack application for UPI merchant transaction analytics and business intelligence.

## Components
- **Analytics Engine** – Python, Pandas, SQLAlchemy, PostgreSQL
- **RAG Engine** – BM25 + dense retrieval + Reciprocal Rank Fusion
- **AI Assistant** – local LLM via Ollama, routes questions to analytics/RAG tools

## Stack
React (JavaScript) · FastAPI · PostgreSQL · Pandas/NumPy · SQLAlchemy · Ollama
